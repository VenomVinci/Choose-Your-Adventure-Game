# The Last Signal

Its a simple text based adventure game I made using Python.

You play as a person who receives a strange signal and has to make different choices to figure out what is happening. Depending on what you choose, the story can go in different directions and lead to different endings.

I made this project to practice Python basics like `if/else`, functions, loops, lists, user input, and the `random` module.

It’s basically a small game where **your choices decide what happens next.**
